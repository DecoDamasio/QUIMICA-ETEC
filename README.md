# 🧪 Game de Materiais de Laboratório

## 📌 Sobre

Jogo educacional desenvolvido para auxiliar alunos do 1º ano do curso técnico em Química da ETEC Júlio de Mesquita na identificação de materiais laboratoriais, suas funções e aplicações em sistemas experimentais.

---

## 🎯 Objetivo

Facilitar o aprendizado por meio de prática interativa, aumentando a familiaridade dos alunos com o ambiente de laboratório.

---

## ⚙️ Funcionalidades

* Perguntas de múltipla escolha com imagens
* Associação entre material, função e sistema experimental
* Níveis de dificuldade progressivos
* Sistema de pontuação
* Uso de dicas (ajudas)
* Cadastro de usuários (aluno/professor)
* Relatórios de desempenho por aluno

---

## 🧩 Requisitos

* Interface simples e intuitiva
* Aplicação multiplataforma
* Armazenamento de desempenho dos usuários
* Boas práticas de acessibilidade e privacidade (LGPD)

---

## 🛠️ Tecnologias

* Flutter
* Dart
